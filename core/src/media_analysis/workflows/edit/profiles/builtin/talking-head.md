Open with the strongest, most self-contained sentence as the hook. Keep the speaker's best take of each point and
drop retakes, false starts, long pauses and fillers. Keep sentences whole. Use cutaways only where the speaker
refers to something shown or the shot would otherwise sit too long. Captions highlight key points in a few words.
