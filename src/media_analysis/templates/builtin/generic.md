No specific template matched this recording, so write a neutral report that still lets someone who did not watch
it understand and act on it.

- Summary: 3-6 sentences: what kind of recording this is, who seems to take part (roles, if names are unknown), and
  the main outcome.
- What the recording is about: the purpose and setting as far as the content shows it.
- Key points: the important information, grouped by topic, in the order it came up, with timecodes.
- Questions and answers: questions asked and the answers given; mark unanswered ones. Write "None" if there were none.
- Decisions, tasks and follow-ups: only what was actually agreed or assigned, with owner and timecode when stated.
  Write "None" if there were none.
- Open points: anything unresolved, unclear or worth checking.
